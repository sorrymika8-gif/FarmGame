# 技能涌现模拟器 — 简要架构设计

## 一、设计原则

- **纯手撸，不依赖第三方战斗框架**：原子池扁平正交，不需要 GAS/ECS 的抽象开销
- **数据驱动一切**：技能由 LLM 运行时生成 JSON，反序列化为 C# 数据，程序只负责执行
- **原子行为独立**：每个原子写成独立 Handler，互不耦合，按需调用
- **异步调度替代同步生成**：涌现链无限延续，执行层通过队列 + 阀门控制资源

## 三、数据层

### 3.1 SkillAtomData

核心数据结构，字段直接对应正交原子池，从 LLM 返回的 JSON 一行反序列化。

```csharp
[System.Serializable]
public class SkillAtomData
{
    // 弹道行为
    public int bounce;           // 弹射次数
    public float tracking;       // 追踪角度 (0 = 不追踪)
    public int pierce;           // 穿透目标数
    public int split;            // 分裂数量
    public bool returning;       // 是否返回
    public float attract;        // 正=吸引 负=排斥

    // 范围规则
    public float aoeRadius;      // AOE 半径
    public ShapeType shape;      // 点/圆/扇形/直线
    public float projectileWidth;// 弹道宽度

    // 数值效果
    public float directHP;       // 正=治疗 负=伤害
    public float dotHP;          // 每秒持续生命变化
    public float moveSpeedMod;   // 移速变化
    public float attackMod;      // 攻击力变化
    public float defenseMod;     // 防御变化

    // 状态
    public float slowPercent;    // 减速百分比 0-100
    public float silenceDuration;// 沉默持续秒数
    public float damageMultiplier;// 易伤/减伤倍率
    public float stealthDuration;// 隐身持续秒数

    // 触发条件
    public TriggerType trigger;  // 立即/被击中时/血量阈值/间隔/击杀时

    // 作用目标
    public TargetType target;    // 自身/单体/区域/全体/最近

    // 时间
    public float delay;          // 延迟释放秒数
    public float duration;       // 效果持续时长
    public float cooldown;       // 冷却时间

    // 元信息（LLM 可选填）
    public string displayName;   // 技能名（纯展示）
    public float projectileSpeed;// 飞行速度
}

public enum ShapeType  { Point, Circle, Fan, Line }
public enum TriggerType { Immediate, OnHit, HPThreshold, Interval, OnKill }
public enum TargetType  { Self, SingleEnemy, Area, AllEnemies, Nearest }
```

## 四、逻辑层

### 4.1 SkillEntity

挂在投射物 Prefab 上，每帧按数据驱动行为。

```csharp
public class SkillEntity : MonoBehaviour
{
    public SkillAtomData data;
    private int pierceRemaining;
    private int bounceRemaining;

    public void Init(SkillAtomData atomData)
    {
        data = atomData;
        pierceRemaining = data.pierce;
        bounceRemaining = data.bounce;
        // VFXComposer 根据 data 激活对应视觉模块
        GetComponent<VFXComposer>().Compose(data);
    }

    void Update()
    {
        // 1. 弹道移动
        if (data.tracking > 0) TrackingHandler.Execute(this);
        transform.Translate(Vector3.right * data.projectileSpeed * Time.deltaTime);

        // 2. 吸引/排斥
        if (data.attract != 0) AttractHandler.Execute(this);

        // 3. 返回检测
        if (data.returning) ReturnHandler.Execute(this);
    }

    void OnTriggerEnter2D(Collider2D other)
    {
        var target = other.GetComponent<CharEntity>();
        if (target == null) return;

        // 应用效果
        EffectApplier.Apply(data, target);

        // 弹射
        if (bounceRemaining > 0) BounceHandler.Execute(this, target);

        // 分裂
        if (data.split > 0) SplitHandler.Execute(this);

        // 穿透检查
        if (pierceRemaining-- <= 0) EntityPool.Instance.Return(this);
    }
}
```

### 4.2 Atom Handlers（静态方法）

每个原子行为独立、可测试。示例：

```csharp
public static class TrackingHandler
{
    public static void Execute(SkillEntity entity)
    {
        var nearest = FindNearest(entity.transform.position, entity.data.tracking);
        if (nearest == null) return;
        var dir = (nearest.position - entity.transform.position).normalized;
        var angle = Vector3.SignedAngle(entity.transform.right, dir, Vector3.forward);
        angle = Mathf.Clamp(angle, -entity.data.tracking, entity.data.tracking);
        entity.transform.Rotate(0, 0, angle * Time.deltaTime * 5f);
    }
}

public static class SplitHandler
{
    public static void Execute(SkillEntity entity)
    {
        for (int i = 0; i < entity.data.split; i++)
        {
            var newData = entity.data.Clone();
            newData.split = 0; // 子弹不再分裂（防止同帧无限分裂）
            var offset = Quaternion.Euler(0, 0, (i - entity.data.split / 2f) * 15f);
            SpawnQueue.Instance.Enqueue(new SpawnRequest
            {
                data = newData,
                position = entity.transform.position,
                rotation = entity.transform.rotation * offset,
                scheduledTime = Time.time // 立即
            });
        }
    }
}
```

### 4.3 EntityPool

基于 Unity 内置 ObjectPool，管理投射物回收。

```csharp
public class EntityPool : MonoBehaviour
{
    public static EntityPool Instance;
    public GameObject skillEntityPrefab;
    public int poolCap = 200;

    private ObjectPool<SkillEntity> pool;
    public int ActiveCount => pool.CountActive;

    void Awake()
    {
        Instance = this;
        pool = new ObjectPool<SkillEntity>(
            createFunc:      () => Instantiate(skillEntityPrefab).GetComponent<SkillEntity>(),
            actionOnGet:     e => e.gameObject.SetActive(true),
            actionOnRelease: e => e.gameObject.SetActive(false),
            actionOnDestroy: e => Destroy(e.gameObject),
            maxSize:         poolCap
        );
    }

    public SkillEntity Get() => pool.Get();
    public void Return(SkillEntity e) => pool.Release(e);
}
```

## 五、SpawnQueue 异步调度系统

### 5.1 问题

涌现链（如 击杀→分裂→击杀→分裂）是核心玩法，逻辑上不应限制链长。
但同步生成会导致单帧实体爆炸（指数增长 3^n），帧率归零。

### 5.2 解决方案

将同步生成改为异步队列调度：所有触发产生的新实体不直接 Instantiate，
而是入队，由调度器每帧按阀门限额取出生成。

### 5.3 SpawnRequest

```csharp
public struct SpawnRequest
{
    public SkillAtomData data;
    public Vector3 position;
    public Quaternion rotation;
    public float scheduledTime;  // Time.time + delay（支持延迟释放原子）
}
```

### 5.4 SpawnQueue（环形缓冲区）

```csharp
public class SpawnQueue
{
    public static SpawnQueue Instance = new(256);

    private SpawnRequest[] buffer;
    private int head, tail, count;
    public int Count => count;

    public SpawnQueue(int capacity) { buffer = new SpawnRequest[capacity]; }

    public void Enqueue(SpawnRequest req)
    {
        buffer[tail] = req;
        tail = (tail + 1) % buffer.Length;
        if (count == buffer.Length)
            head = (head + 1) % buffer.Length; // 满了覆盖最旧
        else
            count++;
    }

    public bool TryPeek(out SpawnRequest req)
    {
        if (count == 0) { req = default; return false; }
        req = buffer[head];
        return true;
    }

    public SpawnRequest Dequeue()
    {
        var req = buffer[head];
        head = (head + 1) % buffer.Length;
        count--;
        return req;
    }
}
```

### 5.5 SpawnScheduler

```csharp
public class SpawnScheduler : MonoBehaviour
{
    [Header("阀门配置")]
    public int maxPerFrame = 10;          // 每帧生成上限
    public int adaptiveFloor = 5;         // 低帧率时降级
    public int adaptiveCeiling = 15;      // 高帧率时提升
    public float fpsAdaptiveThreshold = 40f;

    void Update()
    {
        // 动态调整每帧额度
        int budget = (1f / Time.deltaTime) > fpsAdaptiveThreshold
            ? adaptiveCeiling : adaptiveFloor;

        int poolRemaining = EntityPool.Instance.poolCap - EntityPool.Instance.ActiveCount;
        int spawnCount = Mathf.Min(SpawnQueue.Instance.Count, budget, poolRemaining);

        for (int i = 0; i < spawnCount; i++)
        {
            if (!SpawnQueue.Instance.TryPeek(out var req)) break;

            // 延迟释放：没到时间的跳过（不出队）
            if (req.scheduledTime > Time.time)
            {
                // 注意：环形缓冲区不支持跳过中间元素
                // 实际实现需用优先队列或将延迟请求放到单独的 delayList
                break;
            }

            SpawnQueue.Instance.Dequeue();
            var entity = EntityPool.Instance.Get();
            entity.transform.SetPositionAndRotation(req.position, req.rotation);
            entity.Init(req.data);
        }
    }
}
```

### 5.6 三个阀门

| 阀门 | 作用 | 建议值 |
|------|------|--------|
| `SpawnQueue.capacity` | 队列总容量，溢出丢弃最旧请求 | 256 |
| `maxPerFrame` | 单帧生成上限，防止帧率抖动 | 8~15（动态） |
| `EntityPool.poolCap` | 同屏实体总量上限 | 150~200 |

### 5.7 延迟释放处理

`delay` 原子通过 `SpawnRequest.scheduledTime = Time.time + delay` 实现。
SpawnScheduler 取请求时检查时间戳，未到时间的不生成。

> 注意：环形缓冲区是 FIFO，无法跳过中间元素。
> 有延迟请求时，建议使用独立的 `List<SpawnRequest> delayedList`，
> 每帧检查时间戳，到期后转入主队列。

## 六、LLM 桥接层

### 6.1 LLMBridge

```csharp
public class LLMBridge : MonoBehaviour
{
    public async Task<SkillAtomData> Synthesize(List<MaterialData> materials)
    {
        string prompt = BuildPrompt(materials);
        string json = await CallLLMAPI(prompt);
        var data = JsonUtility.FromJson<SkillAtomData>(json);
        ClampValues(data);  // 安全阀：强制限制在合法范围内
        return data;
    }

    private void ClampValues(SkillAtomData data)
    {
        data.bounce = Mathf.Clamp(data.bounce, 0, AtomConstants.MaxBounce);
        data.split  = Mathf.Clamp(data.split,  0, AtomConstants.MaxSplit);
        data.pierce = Mathf.Clamp(data.pierce, 0, AtomConstants.MaxPierce);
        data.aoeRadius = Mathf.Clamp(data.aoeRadius, 0, AtomConstants.MaxAOE);
        data.tracking  = Mathf.Clamp(data.tracking, 0, AtomConstants.MaxTracking);
        // ... 其他原子同理
    }
}
```

## 七、视觉层

### 7.1 VFXComposer

读取 SkillAtomData，按注册表模式激活对应视觉模块。

```csharp
public class VFXComposer : MonoBehaviour
{
    private AtomVFX[] allVFX;

    void Awake() { allVFX = GetComponentsInChildren<AtomVFX>(includeInactive: true); }

    public void Compose(SkillAtomData data)
    {
        foreach (var vfx in allVFX)
            vfx.gameObject.SetActive(vfx.ShouldActivate(data));
    }
}
```

## 八、关键设计决策记录

| 决策 | 理由 |
|------|------|
| 不用 GAS | 原子池扁平正交，无效果链耦合，GAS 的 Effect Pipeline 是过度设计 |
| 不用 ECS/DOTS | 原型阶段 MonoBehaviour + ObjectPool 够用，数据层是纯 struct 可后期迁移 |
| 不用弹幕引擎 | 弹道行为（追踪/分裂/弹射）由数据动态生成，弹幕引擎的编排器思路不匹配 |
| SkillAtomData 用 class 不用 SO | 技能是运行时动态生成的，不是预制资产，SO 的资产工作流反而是障碍 |
| 隐式效果链不做递归深度限制 | 涌现链是核心玩法，通过 SpawnQueue 异步调度 + 阀门控制执行层资源 |
| SpawnQueue 用环形缓冲区 | 零 GC、固定内存、满时覆盖最旧请求（离玩家最远的最先丢弃） |
| VFX 用注册表模式 | 每个原子视觉独立，Composer 扫描数据自动激活，新增原子只需加子类 |
| LLMBridge 含 Clamp | 防止 LLM 输出超出合法范围，是数值安全的最后一道防线 |
